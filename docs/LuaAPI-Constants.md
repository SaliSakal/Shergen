# Constant tables

*Core — compiled into the main `shergen` project. Used throughout [`LuaAPI-GUI.md`](LuaAPI-GUI.md).*

### TYPE
Element types for `GUI.NewElement`: `ELEMENT`, `LABEL`, `SCROLLBOX`, `SCROLLBAR`, `TEXTLOG`, `TEXTFIELD`.

### ALIGN
`TOP`, `LEFT`, `MIDDLE`, `RIGHT`, `BOTTOM` — used for `PROP.HALIGN`/`PROP.VALIGN`.

### BORDER_TYPE
`NONE`, `INNER`, `OUTER` — used for `PROP.BORDER_TYPE`.

### BUTTON
Mouse button indices: `LEFT`=0, `RIGHT`=1, `MIDDLE`=2, `BUTTON4`=3, `BUTTON5`=4.

### SCROLLBAR_TYPE
`VERTICAL`, `HORIZONTAL` — used for `PROP.SCROLLBAR_TYPE`.

### CALLBACK
Event types for `GUI.SetCallback` / the `callbacks` table in `NewElement`:

- Mouse: `MOUSEOVER`, `MOUSELEAVE`, `MOUSEMOVE`, `MOUSEWHEEL`
- Left button: `LDOWN`, `LUP`, `LCLICK`, `LDBLCLICK`, `LDRAG`
- Right button: `RDOWN`, `RUP`, `RCLICK`, `RDBLCLICK`
- Middle button: `MDOWN`, `MUP`, `MCLICK`, `MDBLCLICK`
- Button 4 / 5: `B4DOWN`/`B4UP`/`B4CLICK`/`B4DBLCLICK`, `B5DOWN`/`B5UP`/`B5CLICK`/`B5DBLCLICK`
- Keyboard: `KEYDOWN`, `KEYUP`, `KEYPRESS`
- Element state: `FOCUS`, `BLUR`, `RESIZED`, `VISIBILITY`, `ANIMEND`
- Touch: `TOUCHDOWN`, `TOUCHUP`, `TOUCHMOVE`, `TOUCHTAP`, `TOUCHDBLTAP`
- Combined: `CLICKTAP`, `DBLCLICKTAP` (fires for both mouse and touch)

### PROP
Used with `GUI.SetProperty` / `GUI.GetProperty` / the property table in `NewElement`. Value type depends on the property:

**Numbers:** `X`, `Y`, `WIDTH`, `HEIGHT`, `BORDER_SIZE`, `FADE`, `FONT_SIZE`, `RANGE_MIN`, `RANGE_MAX`, `CHAR_SCALE_X`, `CHAR_SCALE_Y`, `CHAR_SPACING`, `LINE_SPACING`, `SHADOW_OFFSET_X`, `SHADOW_OFFSET_Y`, `OUTLINE_WIDTH`, `SCROLLTEXT_SPEED`, `SCROLLTEXT_DELAY`, `SCROLLOFFSET_X`, `SCROLLOFFSET_Y`, `SCROLLBAR_TYPE`, `SCROLLBAR`, `SCROLLBAR2`, `GRAYSCALE`, `CURSORSPEED`, `AUTO_SIZE_WIDTH_MAX`, `AUTO_SIZE_HEIGHT_MAX`

**Booleans:** `VISIBLE`, `SCISSOR`, `PASSTHROUGH`, `EVENTCAPTURE`, `AUTO_SIZE_WIDTH`, `AUTO_SIZE_HEIGHT`, `WORDWRAP`, `SHADOW`, `OUTLINE`, `SCROLLTEXT`, `HORIZONTALSCROLL`, `SHOWRICH`, `READONLY`, `PASSWORDMODE`, `CANFOCUS`

**Strings:** `TEXT`, `HINT`, `FONT_NAME`, `TEXTURE`, `TEXTURE2`, `TEXTURE3`, `FALLBACK_TEXTURE`, `FALLBACK_TEXTURE2`, `FALLBACK_TEXTURE3`, `PLACEHOLDER`, `HITMASK`, `SCISSORMASK`

**Colors** (`{R,G,B,A}`): `COLOR1`, `COLOR2`, `COLOR3`, `BORDER_COLOR`, `FONT_COLOR`, `FONT_COLOR_BACK`, `OUTLINE_COLOR`, `SHADOW_COLOR`, `CURSORCOLOR`

**Coords** (`{X,Y,W,H}`): `SUBCOORDS`

**Other (int-backed enums/IDs):** `TEXTURE_ID`, `TEXTURE2_ID`, `TEXTURE3_ID`, `TEXTURE_WIDTH`, `TEXTURE_HEIGHT`, `TEXTURE2_WIDTH`, `TEXTURE2_HEIGHT`, `TEXTURE3_WIDTH`, `TEXTURE3_HEIGHT`, `HALIGN`, `VALIGN`, `ANCHOR`, `BORDER_TYPE`, `SCISSORMASK_THRESHOLD`, `ADDATBOTTOM`, `MAXLINES`, `CURSORPOSITION`, `MAXLENGHT`

### PLATFORM
Read-only info, set at startup: `OS` (`"WINDOWS"`/`"LINUX"`/`"ANDROID"`/`"MACOS"`/`"UNKNOWN"`), `IS_MOBILE`, `IS_DESKTOP`, `ARCH`, `OS_VERSION`.

### Globals
`LUA_VERSION` (currently `"5.5"`), `SHERGEN_VERSION` (currently `"0.7"`).
